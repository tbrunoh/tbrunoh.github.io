# tbrunoh.github.io

The personal site of **Tom Bruno**, Product and Ecosystem Leader in AI Ecosystems at Google, founder of [Korext](https://korext.com) and creator of [ACE, the African Context Engine](https://tbrunoh.github.io/ace/).

Live at **[tbrunoh.github.io](https://tbrunoh.github.io)**. Static pages with no build step, served by GitHub Pages:

- `/` the profile page
- `/ace/` the ACE project page: the problems ACE solves, how it works, coverage, V2 and common questions
- `/writing/` essays, each with its own page, sources and structured data
- `llms.txt` and `llms-full.txt`, a summary and the full text of the site for AI agents, and `sitemap.xml` for search engines
