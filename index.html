Open source

ACE, the African Context Engine

Open source AI for any phone in Africa: USSD, SMS, voice, WhatsApp and MCP, in eight languages across 34 countries, from Swahili and French to Arabic and Amharic. The caller's number picks the country, emergencies get that country's verified numbers first, and every answer names its source. Six decision services on public data, from rain this week to the nearest health facility, work in every country wherever the data exists.

Korext

A governance runtime for AI generated code, with seven open standards that make AI written software traceable, licensable and accountable, and a signed proof bundle for every scan.

Inclusive Skin AI

Skin analysis models often misread darker skin because they learn mostly from lighter skin. This project starts from melanin-rich skin: photo capture, labeling, a skin tone model on the Monk Skin Tone scale and an inference API, with the code open as a reference.
